Eldoria Lehrerzimmer

Fortschritt der Klasse aus den Spielstand-Dateien (.sav oder .json). Die Dateien werden nur hier im Browser ausgewertet und nirgendwohin hochgeladen.

Spielstände einlesen

Dateien hierher ziehen oder auswählen. Gibt es von einer Person mehrere Dateien, zählt die neueste.

Klassenübersicht

Zahl in der Zelle: Anteil der Aufgaben, die beim ersten Versuch richtig waren. Klick auf eine Zeile öffnet die Schülerakte.
90–100 % 70–89 % 50–69 % unter 50 % begonnen ✓ ohne Einzelwerte

Stolpersteine

Aufgaben mit dem geringsten Anteil richtiger Antworten beim ersten Versuch (ganze Klasse)

Fertigkeiten der Klasse

Anteil richtig beim ersten Versuch je Prüfungsteil

So sammeln die Schülerinnen und Schüler ihre Stände ein: Im Spiel Menü → Als Datei speichern, dann die Datei in den vereinbarten Abgabeordner hochladen, zum Beispiel eine OneDrive-Dateianforderung oder einen Ordner im Klassenteam. Diesen Ordner kann man hier mit „Ordner auswählen“ auf einmal einlesen, wenn er per OneDrive auf dem PC synchronisiert ist.
