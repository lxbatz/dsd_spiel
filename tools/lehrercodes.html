🔑 Lehrercodes erzeugen

So geht's: Belohnung wählen, Anzahl eingeben, „Codes erzeugen“ klicken, ausdrucken oder einzeln weitergeben. Die Codes funktionieren sofort im Spiel – man muss nichts eintragen oder hochladen. Die Schülerinnen und Schüler geben den Code im Spiel unter ☰ Menü → 🔑 Lehrercode einlösen ein (oder im Titelbildschirm unter „🔑 Code eingeben“). Jeder Code funktioniert pro Gerät einmal. Gib jeden Code nur an eine Person.
