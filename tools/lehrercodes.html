🔑 Lehrercodes erzeugen

So geht's: Belohnung wählen, Anzahl eingeben, „Codes erzeugen“ klicken. Dann den Block unter 1. in die Datei src/inhalte/codes.js einfügen (vor der letzten Zeile };), committen und veröffentlichen. Die Codes unter 2. ausdrucken oder einzeln an die Schülerinnen und Schüler geben. Jeder Code funktioniert pro Gerät einmal. Gib jeden Code nur an eine Person.
